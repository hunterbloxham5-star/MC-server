04 / TROUBLESHOOTING

Something not working?

“Missing mods” or incompatible modded server

Confirm Minecraft 1.20.1 and Forge 47.4.28. Use the verified shared-mod list on this page once the server audit is complete. Do not assume every catalog entry is required. Remove wrong-version or Fabric builds.

The game crashes before the title screen

Move unrelated JARs out of the mods folder, check dependencies, and verify every mod targets Forge 1.20.1. Add mods back in small groups to isolate a conflict.

Entity models or Fresh Animations are missing or broken

Install Entity Model Features (EMF) and Entity Texture Features (ETF) in the client mods folder. Both are required for Fresh Animations support. They are client-side mods; they do not need to be added to the dedicated server. Also confirm the combined server resource pack is enabled.

Where is the mods folder?

Press Win + R, enter %appdata%\.minecraft\mods, then press Enter. Create a folder named mods if it does not exist.

The server resource pack did not download

In the launcher’s server list, select the server, choose Edit, and set Server Resource Packs to Enabled or Prompt. Reconnect to retry.

Can I use shaders?

Yes, optionally. Install a compatible shader loader and shader pack. If you experience crashes or poor performance, disable shaders and test again.
