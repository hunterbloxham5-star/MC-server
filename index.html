A dedicated game directory/profile prevents unrelated mods and resource packs from conflicting with this server setup.

03 / RESOURCE PACKS & SHADERS

Set up the visuals.

RESOURCE PACKS

Fresh Animations

The package includes Fresh Animations v1.10.4 and seven compatible add-ons.

Choose one setup in Minecraft's Resource Packs menu:

  • Individual add-ons: Fresh Animations, Details, Emissive, Creepers, Classic Horses, Objects, and Spiders.
  • Combined add-ons: Fresh Animations plus All Extensions.

Do not enable All Extensions together with the individual add-ons because their content overlaps. Place enabled add-on packs above Fresh Animations in the priority list.

Entity Model Features (EMF) and Entity Texture Features (ETF) are included; keep them enabled for the entity visuals.

Fresh Mobs for Epic Fight

Version 1.0.0 for Minecraft 1.20.1 is included in the client pack at mods/freshmobs_ef-1.20.1-1.0.0.jar. It helps Epic Fight work with Fresh Animations-style mob models.

  • Required dependency: Epic Fight 20.14 or newer.
  • Client install location: copy the included mods folder into your Minecraft game directory.
  • Download source: Fresh Mobs for Epic Fight on CurseForge ↗.
OPTIONAL GRAPHICS

Shaders

Two shader packs are included for optional visual enhancements. Shaders are not required to join the server.

If a shader causes a crash, low performance, or rendering problems, turn it off under Options → Video Settings → Shader Packs and launch again.

The server remains playable with shaders disabled.

05 / TROUBLESHOOTING

Something not working?

“Missing mods” or incompatible modded server

Confirm that you launched Minecraft 1.20.1 with Forge 47.4.28 and installed all three folders from the complete client pack. Avoid mixing files from unrelated modpacks into this profile.

The game crashes before the title screen

First disable shaders and try again. If the crash continues, check the newest file in .minecraft\crash-reports or share .minecraft\logs\latest.log.

Shaders cause a crash or rendering problems

Shaders are optional. Open Video Settings → Shader Packs and select no shader, then restart the game if needed.

Fresh Animations or entity visuals do not work

Enable EMF and ETF in the Mods list. In Resource Packs, enable Fresh Animations and either its individual add-ons or All Extensions—not both configurations at once.

The server resource pack did not download

Edit the server entry in the launcher and set Server Resource Packs to Enabled or Prompt. Reconnect to retry the download.

Where is the Minecraft game folder?

On Windows, press Win + R, enter %appdata%\.minecraft, and press Enter. If you use a custom game directory, use that directory instead.
