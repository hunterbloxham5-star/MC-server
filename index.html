04 / TROUBLESHOOTING

Something not working?

“Missing mods” or incompatible modded server

Confirm that you launched Minecraft 1.20.1 with Forge 47.4.28 and installed the complete client pack. Avoid mixing files from other modpacks into this installation.

The game crashes before the title screen

First disable shaders and try again. If the crash continues, temporarily move the newest added mods out of the mods folder and share the latest crash report or latest.log.

Shaders cause a crash or rendering problems

Shaders are optional. Turn them off in Video Settings → Shader Packs. The server works without shaders.

Where is the Minecraft game folder?

Press Win + R, enter %appdata%\.minecraft, then press Enter.

The server resource pack did not download

Edit the server entry in the launcher and set Server Resource Packs to Enabled or Prompt. Reconnect to retry.
